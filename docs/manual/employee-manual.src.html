01

เริ่มต้น — ผูกบัญชีแล้วใช้เมนูด้านล่างแชท

ครั้งแรกที่ใช้ต้อง ผูกบัญชี ก่อน: เพิ่มเพื่อนไลน์บริษัท @966nnfkr → กดปุ่ม ผูกบัญชีของฉัน ในข้อความต้อนรับ (หรือกดเมนู ส่งใบลา แล้วกด ผูกบัญชีของฉัน) → กรอก รหัสพนักงาน กับ ชื่อ-นามสกุล → กด ผูกบัญชี ใช้งานได้ทันที รายละเอียดทุกขั้นและกรณีผูกไม่สำเร็จอยู่ใน คู่มือผูกบัญชีเข้าระบบลางาน (แยกอีกเล่ม)

หลังผูกบัญชีแล้ว ทุกอย่างเริ่มจากเมนูด้านล่างแชทไลน์บริษัท

02

ส่งใบลา — 3 ขั้น

  1. กดเมนู "ส่งใบลา"ขั้นที่ 1 เงื่อนไข แสดงโควตาคงเหลือปีนี้ (ลาป่วย · ลากิจ · ลาพักร้อน) และเงื่อนไขของแต่ละประเภท เช่น ต้องแจ้งล่วงหน้ากี่วัน อ่านแล้วกด เริ่มเขียนใบลา
  2. ขั้นที่ 2 กรอกข้อมูลเลือก ประเภทการลา → เลือก ลาเป็น ทั้งวัน หรือ เป็นชั่วโมง → เลือก วันที่เริ่มลา และ วันที่สิ้นสุด → พิมพ์ เหตุผล (อย่างน้อย 3 ตัวอักษร) → แนบรูปได้ที่ แนบไฟล์ (รูปภาพ) ถ้ามี (ไม่บังคับ) แล้วกด ถัดไป
  3. ขั้นที่ 3 ส่งระบบขอตำแหน่ง GPS เพื่อยืนยันว่าคุณกดส่งเอง (บันทึกครั้งเดียวตอนส่ง ไม่ติดตามตลอดเวลา) ตรวจ สรุปก่อนส่ง ให้ถูก แล้วกด ส่งใบลา
  4. ได้เลขที่ใบลาหน้าจอขึ้น ส่งใบลาสำเร็จ พร้อมเลขที่ใบลา และไลน์จะส่งการ์ดยืนยันมาให้ บอกว่าใบลารอใครตรวจเป็นขั้นถัดไป

ประเภทการลาที่เลือกได้

ลาป่วย · ลากิจ · ลาพักร้อน — หักโควตาของปีที่ลา

ลาอื่น ๆ — เลือกแล้วจะมีช่อง ประเภทลาอื่น ๆ ให้เลือกต่อ: ลาคลอด · ลาช่วยภรรยาดูแลบุตร · ลาเพื่อทำหมัน · ลาเพื่อรับราชการทหาร · ลาเพื่อรับการฝึกอบรม · ลาอุปสมบท — เป็นลาตามกฎหมาย ไม่หักโควตา แต่ต้องแจ้งล่วงหน้าตามเงื่อนไข

  • โควตาไม่พอ ระบบไม่ให้ส่งเกินวันคงเหลือ — ถ้าจำเป็นต้องลาเกินจริง ติดต่อฝ่ายบุคคล
  • ลาย้อนหลัง (วันเริ่มลาก่อนวันนี้) ส่งได้เฉพาะ ลาป่วย และ ลาคลอด เท่านั้น ประเภทอื่นต้องส่งก่อนถึงวันลา
  • ช่วงเวลาซ้อนกับใบเดิม ส่งไม่ได้ — ถ้าจะเปลี่ยนวัน ให้ถอนหรือขอยกเลิกใบเดิมก่อน (หัวข้อ 8)
  • ลาติดกันเกินที่กำหนด หรือ ลาหลายวันแต่ไม่แนบเอกสาร ในประเภทที่บังคับ ระบบจะแจ้งเหตุผลให้ทันทีตอนกดส่ง
03

ลาเป็นชั่วโมง (ใช้แทนลาครึ่งวัน)

ระบบไม่มีปุ่ม "ลาครึ่งวัน" แยก — ลาไม่เต็มวันให้กด เป็นชั่วโมง แล้วเลือกช่วงเวลา เช่น ลาช่วงเช้า เลือก 08:30 ถึง 12:00

  1. เลือกประเภทการลาปุ่ม ลาเป็น จะโผล่เฉพาะประเภทที่ลาเป็นชั่วโมงได้ (ตั้งต้นคือ ลาป่วย · ลากิจ · ลาพักร้อน)
  2. กด "เป็นชั่วโมง"ช่องวันที่จะเหลือช่องเดียวคือ วันที่ลา และมีช่อง ช่วงเวลาที่ลา เพิ่มมา
  3. เลือกเวลาเริ่ม และเวลาสิ้นสุดเลือกได้ทีละครึ่งชั่วโมงภายในเวลางาน ใต้ช่องจะบอกว่ารวมกี่ชั่วโมงและหักโควตากี่วัน
  • ช่วงพักเที่ยง (ตั้งต้น 12:00–13:00) ไม่นับ เป็นชั่วโมงลา
  • ลาได้ อย่างน้อย 30 นาที · ถ้ารวมได้เท่าเต็มวันแล้ว ระบบให้เลือก ทั้งวัน แทน
  • วันที่เลือกต้องเป็นวันทำงานของบริษัท
04

แจ้งล่วงหน้าไม่ทันกำหนด — ติ๊ก "เป็นกรณีฉุกเฉิน"

แต่ละประเภทลามีกำหนดแจ้งล่วงหน้า (ตั้งต้น ลากิจ 3 วัน · ลาพักร้อน 7 วัน) ถ้าวันที่เลือกกระชั้นกว่านั้น จะมีกล่องสีเหลืองขึ้นมา ระบบ ไม่บล็อก ให้ส่งไม่ได้ แต่ต้องบอกเหตุผล

  1. ติ๊ก "เป็นกรณีฉุกเฉิน จำเป็นต้องลาทั้งที่แจ้งไม่ทันกำหนด"อยู่ในกล่องสีเหลืองใต้ช่องเหตุผล
  2. พิมพ์เหตุผลที่ต้องลาเร่งด่วนอย่างน้อย 10 ตัวอักษร (ค่าตั้งต้น) ใบลาจะติดป้าย "แจ้งไม่ทันกำหนด" ให้ผู้อนุมัติเห็น

ถ้าฝ่ายบุคคลตั้งประเภทนั้นให้ ไม่เปิดกรณีฉุกเฉิน ช่องติ๊กจะกดไม่ได้และระบบบอกให้เลือกวันที่ใหม่

05

ลาป่วยกะทันหัน + แนบใบรับรองแพทย์ทีหลัง

  1. ลาป่วยวันนี้ หรือย้อนหลัง ส่งได้เลยเลือก ลาป่วย แล้วเลือกวันที่ตามจริง ไม่ต้องติ๊กฉุกเฉิน ใบลาจะติดป้าย ลากะทันหัน ให้ผู้อนุมัติเห็นเอง — อย่าลืมโทรแจ้งหัวหน้างานด้วย
  2. ลาหลายวันที่ต้องมีใบรับรองแพทย์ถ้าลาตั้งแต่จำนวนวันที่บริษัทกำหนด (ตั้งต้น 3 วัน) จะขึ้นกล่องบอกว่า ต้องมีใบรับรองแพทย์ — ยังไม่มีก็ส่งใบลาไปก่อนได้
  3. ได้ใบรับรองแพทย์แล้ว ค่อยแนบเมนู ใบลาของฉัน → แตะใบลานั้น → กล่อง แนบเอกสารเพิ่ม → เลือกรูป → พิมพ์คำอธิบาย (ไม่บังคับ) → กด ส่งเอกสาร แนบได้หลายครั้ง
06

ใบลาของฉัน — ดูสถานะและลำดับการอนุมัติ

  1. กดเมนู "ใบลาของฉัน"เห็นใบลาทุกใบเรียงจากใหม่ไปเก่า พร้อมป้ายสถานะด้านขวา
  2. แตะใบลาเปิด รายละเอียดใบลา ด้านล่างสุดคือ ลำดับการอนุมัติ บอกว่าแต่ละชั้นใครกดแล้ว เมื่อไหร่ และหมายเหตุ
ป้ายสถานะความหมาย
รออนุมัติยังมีผู้อนุมัติบางชั้นที่ยังไม่กด — ยังไม่หักโควตาจริง แต่กันวันไว้แล้ว
อนุมัติแล้วผ่านครบทุกชั้น หักโควตาแล้ว
ปฏิเสธมีผู้อนุมัติไม่อนุมัติ — ดูเหตุผลในลำดับการอนุมัติ วันที่กันไว้คืนให้แล้ว
ถอนแล้วคุณถอนใบลาเอง
ยกเลิกแล้วใบที่เคยอนุมัติแล้วถูกยกเลิกตามคำขอ คืนโควตาแล้ว
ข้าม(ในลำดับการอนุมัติ) ชั้นนั้นไม่ต้องผ่าน เช่น ไม่มีหัวหน้างานในสาย

ทุกครั้งที่มีคนตัดสินใบลาของคุณ ไลน์จะส่งการ์ดแจ้ง — อนุมัติครบจะได้การ์ด ใบลาได้รับอนุมัติแล้ว

07

ผู้อนุมัติขอเอกสารเพิ่ม — ส่งยังไง

ผู้อนุมัติอาจขอเอกสารเพิ่มก่อนตัดสิน เช่น ขอใบรับรองแพทย์ ใบลาจะ ยังไม่ถูกตัดสิน และค้างรอคุณอยู่

  1. ได้การ์ด "ผู้อนุมัติขอเอกสารเพิ่ม" ในไลน์การ์ดบอกว่าต้องการเอกสารอะไร และใครเป็นคนขอ กดปุ่ม แนบเอกสาร
  2. หน้ารายละเอียดใบลาเปิดขึ้นมากล่องแดงด้านบนบอกสิ่งที่ขอ เลื่อนลงมาที่ แนบเอกสารเพิ่ม
  3. เลือกรูป → พิมพ์คำอธิบาย → กด "ส่งเอกสาร"ถ่ายใหม่หรือเลือกจากแกลเลอรีก็ได้ ระบบจะแจ้งผู้อนุมัติให้กลับมาพิจารณาต่อ

ถ้ายังไม่ได้แนบ ระบบจะส่งการ์ดเตือนคุณซ้ำในเวลางาน · แนบเอกสารได้เฉพาะใบลาที่รออนุมัติหรืออนุมัติแล้วเท่านั้น

08

ถอนใบลา / ขอยกเลิกวันลา

สถานะใบลาปุ่มที่เห็นเกิดอะไรขึ้น
รออนุมัติถอนใบลานี้ถอนได้ทันทีไม่ต้องรอใคร วันที่กันไว้คืนให้เลย เหตุผลไม่บังคับ
อนุมัติแล้วขอยกเลิกวันลาต้องเขียนเหตุผลอย่างน้อย 5 ตัวอักษร ระบบส่ง ใบขอยกเลิก ให้ผู้อนุมัติชุดเดิมพิจารณาตามลำดับเดิม อนุมัติครบแล้วใบลาเดิมจะเป็น "ยกเลิกแล้ว" และคืนโควตา
ปฏิเสธ / ถอนแล้ว / ยกเลิกแล้วไม่มีปุ่มใบปิดแล้ว ถ้าจะลาใหม่ให้ส่งใบใหม่

ส่งใบขอยกเลิกซ้ำไม่ได้ระหว่างที่ใบเดิมยังรออยู่ · ถ้าใบขอยกเลิกไม่ได้รับอนุมัติ ใบลาเดิมยังอนุมัติอยู่เหมือนเดิม

09

หน้า "บัญชีของคุณ"

เปิดได้จากปุ่ม ดูสถานะของฉัน (โผล่เมื่อยังไม่ได้ผูกบัญชี) ใช้เช็กว่าบัญชีผูกกับใคร สถานะอะไร และมี LINE User ID ของคุณ ถ้าฝ่ายบุคคลขอให้ส่ง ID ให้กด คัดลอก User ID แล้ววางในแชท

  • ส่งคำขอลงทะเบียนแล้ว รอ HR อนุมัติ — ผูกด้วยรหัสจับคู่แล้ว รอฝ่ายบุคคลกดอนุมัติ
  • บัญชีถูกระงับการใช้งาน — ติดต่อฝ่ายบุคคล
  • คุณยังไม่ได้ผูกบัญชีกับระบบ — กด ผูกบัญชีของฉัน
10

ลาแทนคนอื่น (พนักงานพิเศษ · HR · ผู้บริหาร)

คนที่มีระดับ พนักงานพิเศษ, HR หรือ ผู้บริหาร จะเห็นช่อง ส่งใบลาให้ บนสุดของขั้นที่ 2 เลือกชื่อเพื่อนร่วมงานที่ใช้แอปเองไม่สะดวก แล้วกรอกต่อตามปกติ ใบลาจะวิ่งไปตามสายอนุมัติของ เจ้าของใบ และเจ้าของใบได้การ์ดแจ้งด้วยถ้าผูกไลน์ไว้

11

อาการที่เจอบ่อย

อาการ / ข้อความแปลว่าอะไรทำอะไร
กดส่งใบลาแล้วขึ้นว่ายังไม่ได้ผูกบัญชียังไม่เคยผูก หรือเปลี่ยนบัญชีไลน์กด ผูกบัญชีของฉัน (ดูคู่มือผูกบัญชี)
บัญชีของคุณพ้นสภาพ / ถูกปิดการใช้งานฝ่ายบุคคลปิดบัญชีไว้ติดต่อฝ่ายบุคคล
โควตาคงเหลือ X วัน ลาได้ไม่เกินนี้วันที่ขอเกินวันคงเหลือลดจำนวนวัน หรือคุยกับฝ่ายบุคคล
ลาย้อนหลังทำได้เฉพาะลาป่วย/ลาคลอดฉุกเฉินเท่านั้นเลือกวันที่ผ่านมาแล้วกับประเภทอื่นเปลี่ยนวันที่ หรือคุยกับหัวหน้างาน/ฝ่ายบุคคล
ต้องเขียนใบลาล่วงหน้าอย่างน้อย X วันแจ้งไม่ทันกำหนดติ๊ก เป็นกรณีฉุกเฉิน + เหตุผล (หัวข้อ 4)
ช่วงนี้มีใบลาอยู่แล้ววันที่ซ้อนกับใบที่รอ/อนุมัติแล้วถอนหรือขอยกเลิกใบเดิมก่อน (หัวข้อ 8)
