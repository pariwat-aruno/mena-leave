# คู่มือพาพนักงานเข้าระบบลางาน (รอบแรกทั้งบริษัท)

สำหรับฝ่ายบุคคล · ใช้ตอนพาพนักงานที่ยังไม่ผูกไลน์เข้าระบบ

---

## สิ่งที่ต้องรู้ก่อนเริ่ม

ทะเบียนพนักงานถูกนำเข้าระบบไปแล้ว — ทุกคนมีแถวของตัวเองพร้อมสายอนุมัติครบ
สิ่งที่ยังขาดคือ **ระบบยังไม่รู้ว่าบัญชีไลน์ไหนเป็นของใคร**

LINE ไม่บอกชื่อหรือเบอร์ของคนที่ทักมา บอกแค่รหัสสุ่มประจำตัว
จึงต้องมีจังหวะ "ยืนยันตัวเอง" หนึ่งครั้งต่อคน — พนักงานกรอก **รหัสพนักงาน + ชื่อ-นามสกุล**
ระบบจับคู่กับแถวในทะเบียนแล้วจำไว้ตลอด ไม่ต้องทำอีก

**ฝ่ายบุคคลไม่ต้องกดอนุมัติ** เพราะแถวเหล่านี้นำเข้ามาจากไฟล์ทะเบียนของบริษัทเองอยู่แล้ว

---

## ขั้นตอน

### เตรียม 1 อย่าง
ไฟล์รูป **`onboarding-poster.png`** (อยู่ในโฟลเดอร์เดียวกับไฟล์นี้)
ส่งเข้าไลน์กลุ่ม / ปริ้นติดบอร์ด — มี QR กับขั้นตอน 3 ข้อครบในรูปเดียว

> ⚠️ คนที่ยังไม่ผูกไลน์ **ยังไม่ได้เป็นเพื่อนกับ OA** จึงส่งข้อความผ่านระบบไปหาเขาไม่ได้
> ต้องกระจายรูปนี้ทางช่องทางอื่น (ไลน์กลุ่มบริษัท ไลน์กลุ่มแผนก บอร์ดประกาศ)

### รอบที่ 1 — ผู้บริหารกับหัวหน้างานก่อน
ส่งรูปให้ **ผู้บริหาร 2 คน + หัวหน้างาน 4 คน** ทำก่อน แล้วรอให้ครบ

เหตุผล: ใบลาต้องวิ่งเข้าหาหัวหน้าเป็นชั้นแรก
ถ้าหัวหน้ายังไม่ผูกไลน์ ระบบจะข้ามชั้นหัวหน้าไปให้ฝ่ายบุคคลแทน (ไม่ค้าง แต่ยังไม่ใช่สายจริง)

### รอบที่ 2 — พนักงานที่เหลือ
ส่งรูปเดียวกันเข้าไลน์กลุ่มบริษัท ปล่อยให้ทุกคนทำเอง

### ตามคนที่ยังไม่ทำ
เปิดหน้า **"พนักงาน"** ในระบบ → กรอง **"ยังไม่ผูกไลน์"** → เหลือใครบ้างเห็นครบ
ทุกครั้งที่มีคนผูกสำเร็จ ฝ่ายบุคคลจะได้การ์ดแจ้งในไลน์ด้วย (ดูเฉย ๆ ไม่ต้องกดอะไร)

## เมื่อพนักงานผูกไม่สำเร็จ

พนักงานจะเห็นข้อความ *"ข้อมูลไม่ตรงกับทะเบียนพนักงาน"* เมื่อรหัสหรือชื่อไม่ตรง
สาเหตุที่เจอบ่อยคือ **ชื่อในทะเบียนสะกดไม่เหมือนที่เขากรอก** (ใช้ชื่อเล่น สะกดคนละแบบ)

วิธีแก้ — ออกรหัสจับคู่ให้เป็นรายคน:

1. เปิดหน้า **"พนักงาน"** → กรอง "ยังไม่ผูกไลน์" → หาชื่อคนนั้น
2. กดปุ่ม **"ออกรหัส"** → ได้เลข 6 หลัก + ข้อความพร้อมส่ง
3. คัดลอกส่งให้เขาทางแชท
4. เขาเปิดหน้า **"ผูกบัญชีของฉัน"** → กดหัวข้อ *"ผูกไม่ได้ / ได้รับรหัส 6 หลัก"* → กรอกรหัส
5. **ทางนี้ฝ่ายบุคคลต้องกด "อนุมัติ" ปิดท้ายอีกครั้ง** (ต่างจากทางปกติ)

> รหัสมีอายุ **24 ชั่วโมง** — อย่ากดออกรหัสให้ทุกคนล่วงหน้า ให้ออกตอนจะส่งจริงเท่านั้น
> หมดอายุแล้วกดออกใหม่ได้ไม่จำกัด

## ตารางอาการ → สาเหตุ

| พนักงานบอกว่า | แปลว่า | ทำอะไร |
|---|---|---|
| "ข้อมูลไม่ตรงกับทะเบียน" | รหัสหรือชื่อไม่ตรงกับแถวในระบบ | เช็คสะกดชื่อในทะเบียน ถ้าไม่ตรงให้ออกรหัสจับคู่ |
| "รหัสพนักงานนี้ถูกผูกกับบัญชีไลน์อื่นแล้ว" | มีคนใช้รหัสนี้ผูกไปก่อนแล้ว | เช็คว่าเขาเปลี่ยนเบอร์/บัญชีไลน์ใหม่หรือมีคนผูกผิด — ต้องให้คนแก้ |
| "พบข้อมูลซ้ำในทะเบียน" | มีหลายแถวรหัสและชื่อเหมือนกัน | ระบบไม่เดาให้ ต้องออกรหัสจับคู่ระบุตัวคน |
| "บัญชีของคุณถูกปิดการใช้งาน" | แถวนั้น status เป็น inactive | เปิดบัญชีก่อน แล้วให้ผูกใหม่ |
| "ขณะนี้ปิดการผูกบัญชีด้วยตนเอง" | `self_claim_enabled` ถูกตั้งเป็น FALSE | เปิดกลับ หรือใช้รหัสจับคู่แทน |

---

## เมื่อพาเข้าครบแล้ว (สำคัญ)

เปิดชีต **Settings** → ตั้ง **`self_claim_enabled`** = **`FALSE`**

หลังจากนั้นจะผูกบัญชีเองไม่ได้อีก เข้าระบบได้ทางรหัสจับคู่ที่ฝ่ายบุคคลออกให้อย่างเดียว
เป็นการปิดประตูไม่ให้คนที่รู้รหัสพนักงานกับชื่อของคนอื่นมาผูกทีหลัง

พนักงานเข้าใหม่หลังจากนี้ → ฝ่ายบุคคลเพิ่มในระบบแล้วออกรหัสจับคู่ให้

```bash
python3 scripts/make_onboarding_poster.py
```
