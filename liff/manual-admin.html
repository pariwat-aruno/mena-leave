เพิ่มพนักงานใหม่ (Onboard)

วิธีหลัก: พนักงานผูกบัญชีเอง (ใช้กับการพาเข้าทั้งบริษัท)

คนที่มีชื่ออยู่ในทะเบียนพนักงานแล้ว ผูกบัญชีเองได้ HR ไม่ต้องกดอนุมัติ

  1. พนักงานสแกน QR เพิ่มเพื่อน LINE OA ของบริษัท
  2. ระบบทักกลับพร้อมปุ่ม "ผูกบัญชีของฉัน" ให้อัตโนมัติ
  3. พนักงานกรอก รหัสพนักงาน + ชื่อ-นามสกุล → ใช้งานได้ทันที
  4. คุณ (HR) ได้การ์ดแจ้งว่าใครเข้าระบบแล้ว — ดูเฉย ๆ ไม่ต้องกดอะไร

ต้องตรงทั้งรหัสพนักงานและชื่อถึงจะผูกได้ และหนึ่งคนผูกได้ครั้งเดียว

ทางสำรอง: ออกรหัสจับคู่ 6 หลัก

ใช้กับคนที่ชื่อในทะเบียนสะกดไม่ตรงกับที่เขากรอก จึงผูกเองไม่ได้

  1. เปิดหน้า "พนักงาน" → กรองเฉพาะ "ยังไม่ผูกไลน์" → หาชื่อคนนั้น
  2. กดปุ่ม "ออกรหัส" → คัดลอกข้อความ ส่งให้เขาทางแชท
  3. เขาเปิดหน้า "ผูกบัญชีของฉัน" → กดหัวข้อ "ผูกไม่ได้ / ได้รับรหัส 6 หลัก" → กรอกรหัส
  4. รหัสมีอายุ 24 ชั่วโมง หมดอายุแล้วกดออกใหม่ได้
  5. ทางนี้ HR ต้องกด "อนุมัติ" ปิดท้ายอีกครั้ง

คนใหม่ที่ยังไม่มีชื่อในทะเบียน

  1. ให้กรอกฟอร์มลงทะเบียนตามปกติ → HR ได้การ์ดแจ้ง → กด "อนุมัติ"
  2. หรือ HR เพิ่มให้เองที่แท็บ "พนักงาน" → "+ เพิ่มพนักงานใหม่"

พาเข้าครบทั้งบริษัทแล้ว ควรปิดการผูกบัญชีด้วยตนเอง โดยตั้ง self_claim_enabled = FALSE ในชีต Settings หลังจากนั้นเข้าระบบได้ทางรหัสจับคู่อย่างเดียว

ผูกหัวหน้างาน ↔ ลูกน้อง
  1. แท็บ "หัวหน้างาน" → "+ ผูกหัวหน้างาน"
  2. เลือกลูกน้อง (พนักงานที่ยังไม่มีหัวหน้า)
  3. เลือกหัวหน้างาน (ระบบจะ set is_supervisor=TRUE ให้อัตโนมัติ)
  4. กด "ผูก"

เปลี่ยนหัวหน้าได้ตลอด — ระบบเก็บประวัติทั้งหมด

ตั้งโควตาวันลาต่อพนักงาน

Default ทั้งระบบ ตั้งใน แท็บ "Settings":

  • default_sick_total — ลาป่วย (default 30 วัน/ปี)
  • default_personal_total — ลากิจ (default 6)
  • default_vacation_total — ลาพักร้อน (default 10)

Per user override — แท็บ "โควตา":

  1. เลือกพนักงาน
  2. กรอกโควตาที่ต้องการ (ทั้ง 3 ประเภท)
  3. กดบันทึก
HR เปลี่ยนได้ → ส่งให้ผู้บริหารอนุมัติก่อน apply
ผู้บริหารเปลี่ยน → apply ทันที
แก้กฎเงื่อนไขการลา
  1. แท็บ "กฎ" → "+ เพิ่มกฎใหม่" หรือกดแก้ rule เก่า
  2. ตั้ง:
    • แจ้งล่วงหน้า (วัน) — sick = 0 (ฉุกเฉิน), ลากิจ/พักร้อน = 3-7
    • ลาติดกันได้สูงสุด (0 = ไม่จำกัด)
    • ต้องแนบเอกสารถ้าลาเกิน N วัน
    • หมายเหตุ (แสดงให้พนักงานดูในหน้าลา)
  3. กดบันทึก
อนุมัติใบลา
  1. เมื่อมีใบลาเข้าระบบ → คุณได้ Flex card ใน LINE
  2. กดปุ่ม "อนุมัติ" หรือ "ไม่อนุมัติ" ใน flex โดยตรง
  3. หรือกดเมนู "อนุมัติ" ที่ rich menu → list ทุกใบที่รออยู่

HR กดอนุมัติชั้น 2 — ระบบส่งต่อไปผู้บริหารชั้น 3
ผู้บริหารกดอนุมัติชั้น 3 — final approved + หักโควตาทันที

อนุมัติการเปลี่ยนแปลงของ HR (เฉพาะผู้บริหาร)

เมื่อ HR เสนอเปลี่ยน Settings / โควตา / กฎ → คุณต้องอนุมัติก่อน apply

  1. แท็บ "รออนุมัติ" (เห็นเฉพาะผู้บริหาร)
  2. ดูรายละเอียดที่ HR เสนอ
  3. กด อนุมัติ / ปฏิเสธ
ดู Report
  1. แท็บ "รายงาน"
  2. filter ตามสถานะ (รออนุมัติ / อนุมัติแล้ว / ปฏิเสธ)
  3. กด "ค้นหา"
พนักงานออก (Offboard)
  1. แท็บ "พนักงาน" → กดปุ่ม "แก้ไข" ของพนักงานคนนั้น
  2. กด "ระงับการใช้งาน"
  3. ระบบ:
    • เปลี่ยน status = inactive
    • ถ้าเป็นหัวหน้างาน → ยกเลิก pair ของลูกน้องทั้งหมด (ต้อง pair ใหม่)
    • เก็บประวัติ + Audit_Log ครบ
